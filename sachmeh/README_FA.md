# راهنمای نصب تغییرات پروژه‌ی ساچمه فر

ساختار این پوشه با پروژه‌ات یکی است؛ فایل‌ها را روی همان مسیرها کپی کن:

| فایل | مسیر در پروژه |
|---|---|
| `shop/*.py` (models, admin, forms, views, signals, utils + جدیدها: phone, backends, social) | `shop/` |
| `shop/management/commands/sync_phone_usernames.py` | `shop/management/commands/` |
| `shop/templates/shop/login.html`, `register.html` | `shop/templates/shop/` (جایگزین قبلی‌ها) |
| `sachmeh/settings.py` | `sachmeh/` (فقط یک خط `AUTHENTICATION_BACKENDS` اضافه شده؛ اگر settings را عوض کرده‌ای همان خط را دستی اضافه کن) |
| `templates/admin/*` | پوشه‌ی `templates/` کنار manage.py (حتماً همین‌جا، نه داخل shop) |
| `static/sachmeh_admin/admin.css` | `static/sachmeh_admin/` |

## مراحل
1. `python manage.py makemigrations shop && python manage.py migrate`
2. `python manage.py sync_phone_usernames --dry-run` ← گزارش را ببین، بعد بدون `--dry-run` اجرا کن (username مشتریان قدیمی = شماره‌شان می‌شود؛ ادمین‌ها دست نمی‌خورند).
3. در `checkout_step2.html` و `checkout_step3.html` (و `order_detail.html`) محتوای `checkout_snippet.html` را اضافه کن تا هزینه ارسال دیده شود. (این قالب‌ها را نداشتم، پس خودت اضافه‌شان کن.)
4. در `profile.html` فیلد شماره را `readonly` کن (دیگر از پروفایل قابل تغییر نیست).
5. اگر فیلم‌های سنگین آپلود می‌کنی، در nginx مقدار `client_max_body_size 60M;` بگذار.

## چه چیزی عوض شد
- **ادمین**: تم تیره‌ی هم‌سبک سایت، داشبورد (قیمت‌های روز، آمار، آخرین سفارش‌ها، کانال‌ها)، منوی گروه‌بندی‌شده.
- **کاربران**: ثبت‌نام و ورود فقط با شماره موبایل (ارقام فارسی هم پذیرفته می‌شود). username داخلی همان شماره است. افزودن کاربر از ادمین هم با شماره.
- **هزینه ارسال**: ادمین → تنظیمات سایت → «هزینه ارسال» (تیپاکس و ایرکس جدا؛ حضوری رایگان). به مبلغ نهایی اضافه می‌شود و تخفیف روی آن اعمال نمی‌شود.
- **شبکه‌های اجتماعی**: ادمین → «کانال‌های شبکه‌های اجتماعی» (توکن و شناسه‌ی کانال) و «پست‌های شبکه‌های اجتماعی» (متن + چند عکس/فیلم، هر کدام با توضیح خودش). نتیجه‌ی هر کانال در همان پست دیده می‌شود. اکشن‌های «تست اتصال» و «ارسال پیام آزمایشی» روی کانال‌ها هست.

## نکات مهم
- **تلگرام در ایران فیلتر است**: اگر سرور داخل ایران است، در کانال → «پیشرفته» پروکسی بگذار.
- API ایتا و روبیکا را از مستندات و کتابخانه‌های عمومی تأیید کردم ولی با حساب واقعی شما تست نشده؛ اول «ارسال پیام آزمایشی» را بزن. روبیکا: اگر نوع Video پذیرفته نشود، خودکار به‌صورت فایل می‌فرستد.
- حجم: عکس تا ۱۰ و فیلم تا ۵۰ مگابایت. توضیح هر فایل تا ۱۰۲۴ نویسه.
- توکن‌ها در دیتابیس ذخیره می‌شوند؛ فقط ادمین‌ها به آن دسترسی دارند.
- یک باگ امنیتی هم رفع شد: متن پیام مشتری در ادمین چت بدون escape نمایش داده می‌شد.
- هنوز `DEBUG=True`، `ALLOWED_HOSTS=['*']`، SECRET_KEY ثابت و توکن placeholder در `utils.py` دارید؛ قبل از انتشار عوضشان کن.
- من Django نداشتم، پس کد را اجرا نکردم؛ فقط کامپایل و تست ماک‌شده‌ی بخش ارسال انجام شد. بعد از migrate یک بار ادمین، ثبت‌نام و تسویه‌حساب را امتحان کن و اگر خطایی دیدی متنش را بفرست.
